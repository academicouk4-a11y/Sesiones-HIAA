Bloque 1
Diseñar el
system prompt
Un asistente que otros van a usar necesita instrucciones más cuidadosas que uno personal. Hoy aprenderás a redactar un system prompt de alta calidad: preciso en el rol, claro en los límites y robusto ante entradas inesperadas. La diferencia entre un asistente mediocre y uno indispensable está en la calidad del prompt.
Video de apoyo:
Sonia Jalfin demuestra cómo un bot configurado con el rol de "antagonista leal" produce resultados radicalmente distintos a una IA genérica. El caso conecta con el propósito de entender por qué el diseño cuidadoso de las instrucciones hace toda la diferencia.
Anatomía de un system prompt de calidad
ROL
"Eres un asistente especializado en redacción de propuestas comerciales para empresas de servicios B2B en Latinoamérica."
OBJETIVO Y TONO
"Tu objetivo es ayudar a redactar propuestas claras, profesionales y persuasivas. Usa tono formal pero cercano."
ESTRUCTURA DE RESPUESTA
"Siempre entrega: resumen ejecutivo (3 líneas) + propuesta completa + llamada a la acción."
LÍMITES
"Si no tienes suficiente información del cliente, pide los datos antes de redactar. No inventes precios ni fechas."

Actividad 1 · Bloque 1 · 15 min
Redacta tu system prompt — Diseña un asistente que otros puedan usar
Elige un caso de uso profesional específico y redacta el system prompt completo. Debe ser lo suficientemente claro para que alguien que no lo diseñó pueda usarlo y obtener resultados consistentes.
1
Define el caso de uso: ¿Para qué situación profesional sirve este asistente? Sé específico — no "ayudar con correos" sino "redactar correos de seguimiento a clientes después de una reunión comercial".
2
Escribe los cuatro componentes: Rol · Objetivo y tono · Estructura de respuesta · Límites del asistente. Usa el modelo de la diapositiva anterior como referencia.
3
Prueba mentalmente con dos casos adversos: ¿Qué pasa si alguien le pide algo fuera de su alcance? ¿Qué pasa si la instrucción del usuario es muy vaga? Ajusta los límites si es necesario.
4
Criterio de calidad: Alguien de tu equipo debería poder usar este asistente sin que tú le expliques nada — solo con el system prompt.
→ Este system prompt es lo que pegarás en Gemini Gems en la Actividad 2. Guárdalo con cuidado.

Un system prompt hace la diferencia
Sin system prompt
Respuestas genéricas, tono variable, formato impredecible. El usuario debe dar instrucciones en cada chat.
Con system prompt
Respuestas consistentes, tono definido, estructura siempre igual. El usuario solo da la tarea.

Actividad 2 · Bloque 2 · 15 min
Configura, prueba e intercambia — Lleva el system prompt a Gemini Gems y compártelo en tu sala
Trabaja en tu sala de grupos. Cada quien configura su propio Gem de forma individual. Al terminar, intercambian enlaces dentro del grupo y cada uno usa el asistente de otro compañero con una solicitud real.
1
Crea el Gem con un nombre descriptivo y específico — reconocible para cualquier usuario sin explicación adicional.
2
Pega el system prompt completo: Rol, Objetivo, Estructura de respuesta y Límites. Verifica que estén los cuatro componentes antes de guardar.
3
Prueba con una solicitud propia y ajusta si el resultado no tiene el tono o el formato que diseñaste. Luego genera el enlace compartible.
4
Intercambia el enlace con un compañero de la sala. Usa su asistente con una solicitud real — sin leer el system prompt primero. Anota qué funcionó y qué no.
→ Si no alcanzas a hacer el intercambio, guarda el Gem y toma una captura. Puedes continuar refinando el system prompt después de la sesión.
¿El resultado no convence?
🎭 Tono incorrecto
Especifica el tono con más detalle en el system prompt.
📐 Formato variable
Agrega la estructura exacta de respuesta con un ejemplo.
🚧 Fuera de límites
Escribe explícitamente qué debe hacer cuando no puede ayudar.
Al regresar al pleno
Trae un hallazgo concreto: qué parte del system prompt funcionó para el usuario externo y qué necesitaría ajuste.
